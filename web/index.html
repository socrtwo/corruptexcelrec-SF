About the recovery methods

Auto Repair — tries each method in order, returns the first that produces readable data.

Strict Read — opens the file with strict XML parsing. Confirms the file is actually corrupt.

Lenient XML Repair — rewrites broken XML inside the .xlsx ZIP using lax parsing.

ZIP Recovery — rebuilds the ZIP container itself when the file's ZIP structure is damaged. Uses the Immortal Inflater — a fault-tolerant DEFLATE decoder that walks past truncated/damaged blocks instead of giving up.

Salvage Cells — ignores formatting and pulls every readable cell value into a fresh workbook.

Convert to CSV — for the most damaged files: extracts whatever cells can be read into a CSV.
